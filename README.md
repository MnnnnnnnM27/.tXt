# .tXt
.tXt is a native lightweight Mac clipboard manager.

Installation:
1. Download The Zip From The 'Code' Dropdown Menu
2. Unzip The Folder
3. Add All The Files To A New Xcode Project, And Name It 'tXt'
4. With The Xcode Project Open, Click 'Project' In The Menu
5. Click 'Archive', Then On The Menu, Click 'Custom' or 'More' (Three Dots In A Circle)
6. Then, Name The App 'tXt' And Save To Your Applications Folder


**If You save any file As .tXt with the '.', it will be hidden. Press Command + Shift + Period to show. *THE ZIP IS HIDDEN, SO USE THE COMMAND TO SHOW IT.***
